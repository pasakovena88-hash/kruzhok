КРУЖОК: сборка APK (без Android Studio)

1. Firebase (бесплатно): console.firebase.google.com → создать проект.
   - Authentication → Sign-in method → включить «Электронная почта/пароль».
   - Firestore Database → создать базу → вкладка Rules → вставить содержимое firestore.rules → Publish.
   - Параметры проекта → Ваши приложения → добавить веб-приложение (</>) → скопировать конфиг в www/config.js.
2. GitHub: создайте репозиторий, загрузите в него все файлы этой папки (ветка main).
3. Вкладка Actions → Build APK → Run workflow. Через 5–8 минут внизу страницы запуска будет файл kruzhok-apk.
4. Скачайте, распакуйте, перекиньте app-debug.apk на телефон и установите (разрешите установку из неизвестных источников).

Это отладочная сборка. Для Google Play нужна подписанная release-версия.
